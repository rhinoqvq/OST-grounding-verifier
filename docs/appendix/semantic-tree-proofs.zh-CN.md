# 附录：语义树的数学论证

[返回设计与实现](../design.zh-CN.md)

**先读这一段。** 这份论证写于 2026-10-21，对象是当时的代码（OP8 到 OP20 之间，拆分走代码切点加 Jev 分类的路径）。之后又按两轮外部审查逐项复核，被证伪的断言在原处改写，并标注「审查修订」，不保留错误的版本。到 OP29，有三处和这里描述的不一样：

- 父节点复核（第 3 节 T11）默认关闭，换成了先按整句判定：整句判 S 的句子，里面的 claim 直接继承 S。
- 原文树只在原文超过约 2.6 万 token 时才建，所以和原文树映射有关的论证只在长原文上适用。
- 判定之后加了整句护栏，结构层的报警在整句判为有证据的 S 时会被撤回。

拆分算子（第 2 节）、严重度格和单向聚合（T6）、关系分步核对（T7）、出处门（T9）、桥接（T10′）这些部分，在 OP29 里仍然是原样。

方法：把架构的每一条组合规则翻译成形式命题；能证明的给出证明和**成立前提**；
前提可能失效的地方，先构造反例、**预登记预测**（写在跑之前），
再用真实管线实测，看守卫接不接得住。第 4 节是实测结果。

**总结论（审查修订版）**：系统具有若干**可证明的结构不变量**（撤刀终止、
原文字符覆盖、合取在等价前提下双向分解、子命题反证上传、若干单向标签变换的
计数性质）与**条件化推理规则**；自然语言到结构的映射、作用域识别与证据关系
判断是概率性组件。字符覆盖不等于语义覆盖；局部标签变换不自动保证比例精度或
全管线安全。每项保证在正文中写明其作用范围、前提与分母。本次论证找到的真
反例对应已排期修复项；初版的三处过度断言（S-precision 单调性、严重度序 =
安全性、字符覆盖 = F2）已在原位改写并标注。

## 1. 形式框架

**定义 1（源与后承）** 源文档 D 是有限句子集 {s₁,…,sₙ}，视为一组经典命题。
⊨ 记经典逻辑后承。

**定义 2（理想裁决）** 对 claim φ：

- V*(φ) = **S**，若 D ⊨ₐ φ；
- V*(φ) = **C**，若 D ⊨ₐ ¬φ 且不相容是源**显式**陈述的（R1 规则）；
- V*(φ) = **U**，否则。

**定义 3（作业口径后承 ⊨ₐ）** ⊨ₐ 是把 ⊨ 的推理模式限制为：
逐字/同义改写等值、全称与 generic 例化、向下单调位置的收窄、
全覆盖等同下的等词替换。

一个关键事实：**⊨ₐ 与 ⊨ 互不包含**。

- ⊨ 有而 ⊨ₐ 没有的：析取引入（D⊨A 则 D⊨A∨B，但"B"无出处，口径判 U，见 T9/m10）、
  前件加强（严格蕴涵下有效，口径判 U，见 m11）。被砍掉的恰是"结论里出现了
  前提中不存在的内容"的推理——〔审查修订〕正确的文献对应是 **Parry 的分析
  蕴涵/包含逻辑**（proscriptive principle：结论内容不得超出前提），而非初版
  写的相干逻辑——Anderson–Belnap 的 R 系统里 A→A∨B 是定理，它拒绝的是析取
  三段论。不依赖文献的说法：这是本项目声明的任务政策。
- ⊨ₐ 有而 ⊨ 没有的：generic 例化（"压缩减小体积→传输变快"实例化到网关）是
  缺省推理，经典上不有效。口径有意收下它。

**例外优先条款（审查修订，A8）**：generic 例化被**显式例外**阻断——
"Requests are normally cached" + "Q is an exception and is not cached" 时，
claim "Q is cached" 判 C（缺省逻辑的具体性原则：明确例外优先于一般缺省）。
各定理使用 ⊨ 还是 ⊨ₐ 以各自陈述处标注为准。

**边界假定**：D 自身一致。若源自相矛盾，经典后承爆炸（S、C 同时可证）；架构
从不做全局推理（逐句找证据、逐题独立判），实际退化为"各引各的句子"，不会爆炸，
但 S/C 可能同时出现在不同 claim 上——记为已知边界，不处理。

**定义 4（语义树与分解）** 分解算子 Δ(O) = {A₁,…,A_k}（外加节点类型）。两条保真性质：

- **F1（忠实）**：对每个 i，O ⊨ Aᵢ —— 片段确实是原句断言的内容；
- **F2（覆盖）**：A₁∧…∧A_k ⊨ O —— 片段合起来不弱于原句，幻觉没处藏。

全部单元级裁决的正确性都条件化在 F1 上；漏报防线条件化在 F2 上。

## 2. 分解层定理

### T1（逐字片段引理）
jev 路径的片段是原句的逐字区间（shared-part 的前缀也是逐字区间的拼接），
**在语境解释固定的前提下**不会引入新内容，F1 成立。

**前提会动的东西**（二轮审查 B01 扩充，不止两项）：指称（代词换语境换指称）、
**极性**（片段脱离否定辖域翻转断言方向）、量词与模态强度、时间范围、
归属（谁在断言）、关系限定词（solely/exactly 等，见 T7 的 B02 边界）。
"语境解释固定"意味着这些全部保持——这是强前提，逐字只保证其中一部分。
反例（m02）："He left without locking the office **and** setting the alarm"
在 and 处逐字切开，右片段 "setting the alarm" 脱离 without 的辖域，从
¬设闹钟变成正断言设闹钟——逐字却不忠实，F1 被破坏。
守卫三层：keep_whole 选项明示"否定辖域盖住两侧"；shared-part 若把前缀切在
"He left without"，组装出的第二句反而极性正确；两片段若被误判全 S，round 4
整句复查兜底。指称问题由 inherited_spans（判定时始终可见原句）+ 语境限定注
（语境只用于消解指称）处理。

### T2（平铺定理，及其被证伪的角落）
**命题**：若所有片段保留，则片段 ∪ 连接词 ∪ 修剪掉的标点 = 整句（对
bounds/starts 构造归纳可证：第 i 片段 = [starts[i], bounds[i+1])，相邻片段间
恰好隔一个 marker 区间）。F2 由构造成立——propose_jev 的 docstring 这样声称。

**反例（代码级证明 + m07 实测）**：display 不足 3 词的片段被置 None 丢弃
（propose_jev.py:391-394），其文本**不属于任何单元**；只要同句仍有 ≥2 个
片段存活，整句不回退。此时平铺破洞，最多泄漏 2 个词——但 2 个词足以装下一个
完整谓词断言（"…but **failed**"）。
更要命的是兜底失效的代码级证明：round 2.5 的确定性覆盖检查把
anchor_spans **和 inherited_spans** 一起算进掩码（select.py:115），而每个
jev 片段的 inherited_spans 就是整句——掩码恒全真，gaps 恒空，**该检查在
jev 路径上永不触发**。剩下的唯一防线是 round 4，而它只在"全 S"时启动：
构造 m07 使一个片段判 U，泄漏即无人看守。误差方向：**危险**（幻觉内容
逃出验证，默默不出现在输出里）。

### T3（合取分解定理）
**命题**：若 O ≡ A∧B，则 (i) D⊨O ⟺ D⊨A 且 D⊨B；(ii) D⊨¬A ⟹ D⊨¬O。
经典有效（∧-消去/引入、逆否）。所以 two_facts 切分在 **O ≡ A∧B** 前提下双向保真。

前提失效的三类反例：

1. **集体/配对谓词**：met、together、total、**respectively**（见 T4）；
2. **自然语言 and 的时序增量**："deployed the fix and restarted" 的 and-then
   会话隐涵不是 ∧ 的真值条件。切开后顺序内容不被任何单元承载。架构的立场
   （Grice：会话隐涵可取消、不入真值条件）数学上站得住，但作业口径若把
   顺序颠倒算 C，这就是已测得的 OP8 sequence 失误来源之一；
3. **否定辖域**（T1 的反例在此复现）。

守卫：keep_whole/not_boundary 选项文本点名了这三类 + round 4。
**诚实记一笔缺口**：经 family 多数规则接受的 two_facts 风格（share 质量和
+ two_facts 对最强对手的相对多数，propose_jev.py:319-352）**没有绝对门**——
注释声称 recomb 绝对门为多数决背书，但 recomb 只跑 shared 风格。two_facts
经 family 以 p<0.60 过线时，唯一兜底是 round 4。

### T4（shared-part 组装 = 分配律前提）
**命题**：组装 "P A and B" ↦ {P·A, P·B} 保真 ⟺ 谓词前缀 P 对 and 可分配：
P(a∧b) ⟺ P(a)∧P(b)。对分布式谓词成立；对集体读法与 respectively 配对失效
（"A 和 B 分别涨 40%、10%" 组装成 "A 和 B 涨 40%" + "A 和 B 涨 10%"——两条都是假命题）。
recomb 检查（"合起来是否恰好断言原句，不多不少"）正是对这条分配律前提的
**运行时检验**，失败则撤销切分。m04a 的设计使任何分配律违规直接显形为假 C
（源里 B 只涨 10%）。

### T5（可切性定理：实然性准则）
**命题**：连接词两侧可以切成被断言的独立单元 ⟺ 该连接词**双侧实然**
（veridical：整句为真则两侧各自为真）。

证明：实然性正是 "O ⊨ A 且 O ⊨ B"（F1）的定义。逐条分类：

| 连接词 | 实然？ | 架构处置 | 一致？ |
|---|---|---|---|
| because / so / therefore | 双侧实然（because 预设双侧） | 切 + CAUSE 节点 | ✓ |
| but / however / although / whereas | 双侧实然 | 切 + CONTRAST 节点 | ✓ |
| then / after which | 双侧实然 | 切 + SEQUENCE 节点 | ✓ |
| and（子句级） | 双侧实然 | 切，无关系节点（真值函项） | ✓ |
| **if / unless** | **非实然**（断言前件是无中生有） | keep_whole | ✓ |
| **or** | **非实然**（两支都不被断言） | keep_whole | ✓ |
| may / reported | 非断言 | keep_whole | ✓ |
| when | 歧义（情节性=实然，generic=条件性） | keep_whole 选项点名 | 边界 |

节点种类枚举（CONDITIONAL/DISJUNCTION/REPORTED）与逻辑性质一一对应——
**这张分类表就是架构"数学上说得通"的核心证据**：哪里切、哪里不切，不是
工程直觉，是实然性的直接推论。
但分类本身是 Jev 的概率判断：若 lead-if 被误判成 cause_link，前件会被当
断言去判——源否定前件时产出假 C（条件句与假前件相容，真裁决是 U）。
m01a 专攻这一点。Sobel 型前件加强（m11）与捏造析取支（m10）则测 keep_whole
路线上裁决问题 + grounding gate 的组合是否实现了 ⊨ₐ 对 ⊨ 的那两处有意偏离。

## 3. 裁决层定理

### T6（严重度格与单向保守聚合）
裁决格：S < U < C（_SEVERITY），关系单元裁决 = max(自身, 成员)。

- **(a) C 上传健全**：若成员裁决正确（D⊨¬Aᵢ）且 F1 成立（O⊨Aᵢ），则
  D⊨¬O，V*(O)=C。逆否命题，经典有效。✓
- **(b) U 上传健全**：D⊭Aᵢ 且 O⊨Aᵢ ⟹ D⊭O。✓
- **(c) S 方向非定理**：全成员 S 推不出整体 S——不是 ∧-引入失效（那是有效的），
  而是 F2 可能失效（切分丢了"同一个"、丢了因果链、丢了共享辖域）。架构自知
  （aggregate.py 文档原文），补偿是 round 4 全 S 复查 + 父裁决优先。
- **(d) 不完备定理（真反例，m03）**：存在 D⊨¬(A∧B) 而 D⊭¬A、D⊭¬B
  （D="恰好一台失败"，A/B="A 失败"/"B 失败"）。成员各判 U 都**正确**，
  max 聚合到顶是 U，而句级合取的 V* 是 C。**联合矛盾对"只读成员标签的聚合函数"不可表达**
  （审查修订：不是"任何逐单元架构"——补联合约束检查即可破，列为后续战役；
  有限模型证明：D₁=无信息 与 D₂=恰一真 给出相同成员标签 (U,U) 而 V* 不同）；
  方向为严重度低报，输出仍被标记。

**推论（审查修订，A2）**：初版在此用一个不等式"聚合 ≤ V*"同时承载多条
安全性质，是错的——该序关系里 S≤C 成立，而"输出 S、真值 C"恰是最危险的
放行；且"从不把 U/C 报成 S"还需要 **F2**（分解不弱于原句）这条初版漏写的
前提：全成员 S 判对 + F2 失效正是 aggregate=S、V*=C 的通道（T6c 自己承认、
round 4 为之存在）。正确的表述是**分项条件化目标**：

- （S 安全）output=S ⟹ D ⊨ₐ claim，成立前提 = 成员裁决正确 ∧ F1 ∧ F2；
  F2 是概率守卫（recomb、round 4），所以这是条件化目标，不是无条件定理；
- （C 安全）output=C ⟹ D ⊨ₐ ¬claim 且显式，成立前提 = 判 C 的那条路径
  （成员 C / staged opposite / 对立性过滤幸存）各自的判定正确；
- （联合矛盾不完备，T6d）成员 U,U 正确时聚合到不了 C——输出仍是被标记的
  U，不产生放行，但严重度低报。

实测侧写（非证明，数字按二轮审查 B09.2 改为精确分数）：random200（OP8）里
S 输出 143 个、金标非 S 的 4 个（1 个无争议实漏 + 2 个非 claim 问句头 +
1 个争议转移）：**4/143 = 2.8%（S 输出口径）、4/200 = 2.0%（全样本口径）**。
历史记录的"1.4%"无法从现存文件以整数分子重构，弃用。

### T7（staged 关系检查：单调性与方向）
形式化：claim 链 L_c=⟨x_c, r, y_c⟩，源链 L_s=⟨x_s, r, y_s⟩。
判定规则：双侧 matches→S；任一 opposite→C；任一 different/flat→U。
matches 的定义含"同一物或其实例/子集"。组合规则本身（代码）是查表，健全性
全押在两条语义前提上：

**前提一：收窄的位置单调性。**
"实例/子集算 matches"只在**向下单调位置**有效：

| 位置 | 收窄有效？ | 反例/佐证 |
|---|---|---|
| 全称/generic 语境 | ✓（全称例化） | m05c |
| **存在语境** | **✗**（∃客户丢数据 ⊭ ∃企业客户丢数据） | m05a；反方向反而有效（m05b） |
| 条件/因果**后件** | **✗**（A→(B∨C) ⊭ A→C） | m06 |
| 条件**前件** | 经典 ✓，缺省/反事实 ✗ | m11 |

SIDE_OPTIONS 的 matches 条款**不区分位置**——这是口径里"纯收窄=S"的数学
软肋，r05 待裁定问题的内核正是它：**裁定依据应是"收窄发生在什么单调性位置"，
而不是表面的收窄/放宽方向**。（r05 的 "clients→mobile clients" 在 generic
读法下是 ✓，在存在读法下是 ✗——它难裁不是口径模糊，是句子的量化读法歧义。）

**前提二：方向保持（预登记的预期失败，m09）。**
sequence 是非对称关系 r(x,y)≠r(y,x)。而检查链对交换 x,y **不变**：rel1 明文
"任意方向"找链；rel2/rel3 按内容把 claim 侧对到源链"对应侧"——内容相同的
两个事件无论顺序如何都 matches。形式上：检查函数在成员置换下不变，而待验
关系不是——**该检查不能区分 r(x,y) 与 r(y,x)**，源明说"先重启后部署"、答案
说"先部署后重启"时组合出假 S，危险方向。cause 理论上同病（"A causes B" vs
"B causes A"），实际依赖 Jev 对 "corresponding side" 做角色对齐还是内容对齐——
无形式定义，记为同一缺口的弱化形态。这正是修复清单第②项的数学根源：
顺序必须**代码化比较**（证据句内事件位置 vs 答案事件顺序），不能指望逐侧匹配。

### T8（CONTRAST 真值函项豁免）
"A but B" 的真值条件 = A∧B；对立义是约定隐涵（Frege/Grice），不入真值条件。
所以 contrast 关系单元不做 staged 检查、直接成员聚合——**健全**（由 T6a/b），
但〔审查修订，A3〕**不完备**：contrast 真值条件即合取，T6d 的联合矛盾限制
原样适用（exactly-one 型反例下成员 U,U → 聚合 U，到不了 C），初版的"完备"
二字删除。残余：修辞对立义本身不被验证（源平铺直叙 A、B，答案
加个 but——口径认为隐涵不是 claim 内容）。有意边界，m12 做对照。

### T9（grounding gate：单向算子定理）
代码分支直接可证：gate 只执行 S→U（apply_grounding_gate 仅在 verdict 为 S 时
动作），从不产生 S、从不产生 C。⟹〔审查修订，A1〕可证的只有计数性质：
**错误 S 的绝对数量不增加、不产生新 C**。初版"不可能降低 S-precision"是错的
——比例精度 = 正确S/全部S，若误触发集中在正确侧（设正确 S 保留率 α、错误 S
保留率 β，则精度不降 ⟺ α≥β），选择性删除正确 S 会拉低比例。而 If/When 封顶
误伤**实测恰好落在正确侧**（verbatim 支持的内容被封），即 α<β 的风险是真实
的——这正是修复①的必要性来源之一。评测须分开记录：错误 S 数量、S 比例精度、
金标应标被放行数。
同时 gate 是 ⊨ₐ 拒绝 ∨-引入的**实现机制**：∨-intro 在经典上有效（m10 整句
经典可判 S），gate 用"析取支内容无出处"把它压回 U——出处轴压过真值轴，
两轴分离在此落地为一个方向受控的算子。

### T10（bridge rescue = 等词替换推理的三前提）〔历史版：P2 已由 br5 补上，现行陈述见 T10′（第 6 节）及其二轮审查修订〕
推理模式：P1) D⊨ total(a→b) 或 a=b；P2) D⊨ φ(b)（或 ¬φ(b)）；结论 φ(a)。
经典上这是等词替换/全覆盖传递，**三条前提**缺一不可：

- **P1 全覆盖**：br2 显式检查（claim-free 措辞，实测把污染 0.76→0.35）✓
- **P2 谓述绑定**：br3 选出的性质句必须**谓述 b**。br4 明文"忽略主语、只比
  性质"——绑定**没有被检查**。conflict-189 的假 C 就是这条前提缺失的实例：
  性质句谓述第三实体 c，φ(c) 被当成 φ(b) 用。m08b 合成复现。**危险方向**
  （产假 S/假 C），修复方向由证明唯一确定：补一问"该句的性质是否谓述 b"。
- **P3 语境外延性**：等词替换在引述/命题态度语境（"报告称 X"）内无效
  （Frege 的内涵语境）。未检查；现状缓解是 bridge 只对 flat 的 FACT 单元触发，
  REPORTED 类内容多半走不到这。记为归属轴（第三轴）的待办。

另外 bridge 的触发面是形式受控的：只作用于 flat U，失败回 U（保守），成功才
产 S/C——所以 P2/P3 的洞只在"普通裁决恰好平坦"时暴露。

### T11（parent override：决策规则，非定理）
round 4 发现整句裁决与全 S 成员矛盾时，至少有一处为假：成员判定错、整句判定
错、或 F2 失效。三者不可区分，架构选择信整句——依据是"节点只是对不可变原文
的解释，解释与原文冲突时回到原文"（tree.py 的设计公理）。这是**最小解释承诺**
的决策规则：整句是唯一不经过任何解释步骤的对象。可错（整句判定本身可能错），
但错误方向仍保守（override 只把 S 拉下来，从不抬上去——sentence_judgment 非 S
才触发）。

### T12（证据构造性约束）
decide_verdict：定裁决（S/C）无句子过相关性门、且排名最高句不及下限时，强制
退 U（no_evidence_for_*）；渲染合同拒绝无引用的 C。形式上这是**构造性要求**：
不存在可出示的证据句 ⟹ 不输出定裁决，等价于把"非构造性的确信"全部折叠进 U。
再次只伤完备性、不伤健全性。平坦规则（top<0.55 → U + low_confidence）同理：
V 是部分函数，未定义处一律保守补全。

## 5. 结论

**架构在数学上说得通的部分**（定理，代码层查表组合在前提下经典有效）：
实然性切分准则（T5 分类表）、合取双向保真（T3）、严重度格的单向保守聚合
（T6 推论）、gate/证据/平坦规则的单向性（T9/T12）、contrast 豁免（T8）、
bridge 的推理模式本身（T10）。〔审查修订〕误差方向的正确表述：在"成员裁决正确 ∧ F1 ∧ F2"成立处，
组合层不产生新的危险放行；F2 与各判定正确性是概率性前提，所以这是条件化
性质而非全局定理。82.5% 实测里 S 输出 97% 正确、错误堆在 U/C，是与该条件化
性质**相容的侧写**，不是它的证明。

**被本次论证证伪/确认的真洞**（全部有反例，按危险度排，括号内为实测状态）：

1. **bridge 缺 P2 绑定前提**（T10）：189 类假 S/C，危险方向，**m08b 合成复现
   了假 S**。修复由证明唯一确定（补一问"性质句是否谓述桥接实体"）。
2. **sequence 方向盲**（T7 前提二）：staged 层置换不变被 m09 实锤（关系单元
   判了 S）；系统级靠 round 4 单点概率防线兜住了干净文本，脏文本（OP8 回归）
   会漏。修复清单②是把概率防线换成代码防线。
3. **平铺破洞 + 覆盖检查空转**（T2）：<3 词片段逃出验证（m07 实测 "failed"
   不在任何单元里）；select.py 的确定性检查被 inherited_spans 永久短路。
   修法同时让 T2 重新成为定理：真的并入邻居片段，或覆盖检查改用 anchor_spans。
4. **收窄不分单调性位置**（T7 前提一）：存在语境、后件位置的收窄不健全；
   实测裁判自己判对了 m05a/b/c（0.93–0.99）但 m06 只靠平坦勉强兜住。
   r05 的裁定建议按"位置单调性"重述口径。
5. **联合矛盾对只读成员标签的聚合不可表达**（T6d，二轮措辞统一）：m03 实测
   成立；是该聚合函数族的下界，不是逐单元架构的下界（联合约束检查可补），
   README 里值得作为口径说明写出。

实测还额外给了一个正向结论：**两条最怕的"分解制造假命题"路线都没能穿透守卫**
——否定辖域（m02）被 shared-part 前缀机制以意料之外的优雅方式化解（前缀把
否定一起带走，组装句极性天然正确），respectively（m04a）在切点分类层就被拒绝。
加上 m01（if）、m10（∨-intro）、m11（Sobel）全部按设计意图落在 U，
分解层的实然性准则 + keep_whole + gate 这三道闸在 17 例对抗集上零穿透。

另有两笔诚实记录的债务：family 多数接受的 two_facts 无绝对门（T3）；
when 的 generic/情节歧义与 P3 内涵语境未检查（T5/T10）。

## 6. 修复后的再证明（2026-10-21，三洞修复）

三个洞按证明指出的缺失前提修复，修复后对应命题重新成为定理：

### T2′（平铺定理恢复）
修法：低于 3 词下限的片段不再丢弃，而是**撤销制造它的那一刀**（左邻刀，
片段 0 则撤第一刀），文本并回邻居；循环至无小片段或无刀可撤（退整句）。
**定理**：循环每轮严格减少一刀，必然终止；终止时要么无接受刀（整句单元，
平凡覆盖），要么所有片段 ≥3 词且 bounds/starts 构造保证片段∪连接词∪修剪
标点 = 整句。**平铺不变量由构造成立**——〔审查修订，A4〕它证明的是 **F_text（原文字符
完整覆盖）**，不是 F2（语义覆盖 ∧Aᵢ⊨O）：共同存在对象反例（∃x[读(x)∧写(x)]
拆成 ∃读 ∧ ∃写，字符全保留而语义变弱）表明语义内容可以住在片段之间（同指
绑定），任何字符覆盖都够不到。F_text 关闭的是 m07 型"内容整体逃逸"；F2 的
守卫仍是 recomb 检查与 round 4，概率性，初版"F2 恢复为定理"收回。
纵深防御同时复活：select 的确定性覆盖检查不再把"覆盖整句的 inherited span"
计入掩码（那是裁判语境，不是解释覆盖），所以未来任何破坏平铺的回归都会
触发整句回退，而不是静默漏词。guard 与 build 共用同一个 `_fragment_layout`
以杜绝两处逻辑漂移。

### T7′（sequence 组合健全性恢复）
修法有两半，对应证明里的两个缺口：
1. **claim 侧顺序入定义**：sequence_link 选项文本改为"LEFT 先发生，然后
   RIGHT"——Jev 选中该选项即断言了 claim 的方向，方向不再是代码的硬编码
   猜测，而是分类答案的一部分；
2. **源侧顺序单独一跳**（rel4，仅 sequence 关系）：left_first / right_first /
   no_order 三选。组合规则：right_first（自信）→ C（源显式陈述了相反顺序，
   落在 R1 的"inverted condition"族）；left_first → 继续原有两侧匹配检查；
   no_order/平坦 → U（顺序无出处）。
**定理**：修复后检查函数在成员置换下**不再不变**（rel4 的答案随置换翻转），
置换不变性论证失效，原反例失去存在性基础。健全性：right_first→C 由"源显
式断言 r(y,x) 且 r 非对称"推出 D⊨¬r(x,y)；left_first+双 matches→S 由 T7
原组合规则加方向前提补全。残余：cause 的方向仍依赖 Jev 对"对应侧"的角色
对齐（无 rel4），记为弱化形态的已知边界。〔审查修订，A9〕补一条初版漏写的
前提：right_first→C 的健全性要求两侧指称**同一对事件实例**——源中同类事件
多次发生时（两次重启夹一次部署），claim 的存在读法（"先于某次重启"）可被
另一实例满足，按类型比较会产假 C。rel4 无实例绑定，这是已证明的机制风险
（audit08 探针预登记待跑）；缓解猜想（多实例使分布平坦→退 U）未证实。

### T10′（bridge 前提集补全）
修法：新增 br5（claim-free，只看两句）："性质句的陈述是否关于桥接句连到的
那个目标实体？"——即缺失的 **P2b 谓述绑定前提**。门：br5 < 0.55 则救援不
触发，平坦 U 原样保留（保守失败）。
**定理（审查修订，A5）**：初版"前提集对结论完备"是错的。br2 把等同/别名
与路由/子集/部分-整体捆成一个 "total"，而性质传递规则因**关系类型×性质类型**
而异：a=b（外延语境）⟹ 任意 φ 可替换；a⊆b ⟹ 只传递全称成员性质
（∀x∈b P(x) ⟹ ∀x∈a P(x)），**不传递集合级性质**（基数反例：mobile ⊆
registered ∧ |registered|=100 ⊬ |mobile|=100——br2/br4/br5 全过而结论仍假）
也不向下传递存在性质（∃x∈b ¬P(x) ⊬ ∃x∈a ¬P(x)）。br5 补上的是谓述绑定
（P2b），不是通用传递性。当前实现不区分关系类型：这是一个**已证明的机制
风险**，暴露面受"仅平坦触发 + br4 匹配"约束（900 条实测 3–4 次触发），
代码守卫（br2 拆问 + 性质全称性条件）列入下一批修复。P3 外延性仍为归属轴
待办。br4 的"忽略主语"设计保留——它负责 P2a，主语的事
归 br5——分工后每个问题仍是单跳。

## 7. 清单①③④的必要性与相容性证明（2026-10-21，修复前预登记）

### 7.0 框架：两类可容许算子与三条不变量

第 1–6 节已证的性质浓缩为三条不变量：

〔审查修订，A1/A2/A7：初版的 I1（条件概率不变式）与 I2（≤V* 序）被证伪，
换成下面三条**可证的计数/集合性质**，比例精度另行测量〕

- **N1（错误 S 计数）**：错误 S 的绝对数量不增、不产生新 C（注意：这不
  蕴含 S 比例精度不降——那取决于误触发落在正确侧还是错误侧，需测量）；
- **N2（条件化危险界）**：output=S ⟹ D⊨ₐclaim，在"判定正确∧F1∧F2"前提
  下成立（概率性前提，非无条件）；
- **N3（标记覆盖）**：被标记集合（U∪C）对幻觉 span 的字符覆盖不减——
  成立条件：单位边界固定、不触发下游重写。

观察：管线里每一个修改裁决的算子都属于两类之一——

- **K1（向 U 的单调过滤）**：S→U 或 C→U，别无它动。gate（T9）、证据约束
  （T12）、平坦规则都是 K1。**引理 K1（审查修订）**：任何 K1 算子保 N1
  （不增错误 S、不产生 C）与 N3（S→U 使标记集变大，C→U 使其不变——U 仍是
  标记），枚举三种输入即证。K1 **不**保证 S 比例精度（选择性删正确 S 会拉低
  比例，A1），也不满足"输出 ≤ V*"（gold=S 被压成 U 即越过 V*，A2）——
  这两条本就不该是 K1 的目标。
- **K2（平坦升级）**：仅作用于 low_confidence 的 U，凭**可引用的构造性前提**
  升级为 S 或 C，前提不齐则原样保留。bridge（T10′）是 K2 的范本。
  **引理 K2（二轮审查修订，B04/M14）**：前提集完备时，K2 升出的 S 满足
  N2；K2 升出 C 是**合法行为**（真实矛盾的平坦 U 升 C），所以 N1 的
  "不产生新 C"只对 K1 成立，不是全体算子的共同不变量。K2 对 N3 的收缩面
  被平坦集合约束。
  〔二轮审查删除：旧版"K1 与 K2 任意叠加保持 I1–I3、域不交故安全"的组合
  定理——与 7.4 的修订矛盾且已被 B04 证伪。正确的组合论证只有一种：对固定
  管线顺序逐步验证每个算子的前置条件与**最终状态的检查义务**（见 7.4），
  其中"救援升出的 S 是否重新通过 gate"是源码层面确认存在的缺口。〕

### 7.1 ①If/When 封顶误伤

**必要性（公理违反）**。定义 3 把"逐字"放进 ⊨ₐ 的第一条：逐字出现于源的
内容必然有据。gate 开火的正当条件是"诊断部件内容不在源中"。实测存在
源中**逐字在场**而 grounding 探针给 0.02–0.47 的实例（OP8 的 18+ 处、
900 条里 147 次无金标重叠的封顶、random200 的 ~3/35 ≈ 1.5pp）。
"内容在场"是**语法性质**（归一化后的子串/词元包含关系），可判定；让一个
概率测试去否决一个可判定为真的语法事实，就是实现违反定义 3。修复不是
调优，是恢复公理。

**修法形状与相容性**。核心：**代码级在场见证**——诊断部件文本（归一化后）
逐字出现于某源句 ⟹ 封顶被压制。它是一个前提为语法确定性的 K2 型豁免
（见证强度最高：在场是字符串性质，p=1）；对改写式在场（paraphrase），
见证**失败则封顶照旧**（fail-closed）。〔审查修订，A6〕两点精确化：
(i) 见证对 gate 自己的接地谓词（内容在场，按 gate 问题的定义**包含**否定/
条件/转述语境内的在场）是判定性的；否定语境的危险在裁决问题 V 判错 S，
那不是 gate 的轴——但"在场⟹支持"不成立（"It is false that X" 含 X），
见证绝不能升 S，只能免除封顶；(ii) 初版"漏放面零扩大"是相对新系统的说法，
相对旧系统取消一次偶然拦截可能放行——这是实测命题不是定理，实测结果：
900 复跑片段检出 94.9→95.3，未降。否定语境探针（audit06/10）预登记待跑。
m10（捏造析取支 "a hardware fault"）的部件在源中无此内容 ⟹ 见证失败 ⟹
照旧封 U——T9 的存在意义不受损。
**预登记验收**：m10、m11 必须仍 U；RAGTruth 片段检出不得降；
random200 的 S 桶正确率（97%）不得降。

### 7.2 ③成员拖累

**必要性（两条判定路径的不一致未被消解）**。T6 的健全性前提是成员裁决
正确。实测形态：staged 检查找到链句、双侧 matches（own=S），而某成员的
独立裁决平坦退 U ⟹ 合并被拖成 U（900 条里 relation_merged_from_SUPPORTED
98 次，random200 ~4/35 ≈ 2pp）。但 T5 已证链接词双侧实然：
D ⊨ link(x,y) ⟹ D 断言 x 且 y；T7 的 matches 又已证成员侧 ⊑ 源侧。
两者合起来：**staged_matched 本身蕴涵成员有据**。于是"成员平坦 + 关系
matched"是系统内部的逻辑不一致，而现行 max 聚合总是信平坦的那个——
信的是**无见证**的判断（平坦=无可引句），弃的是**有见证**的判断（链句
sid + 两个单跳检查）。T11（父裁决优先=信息多者胜）和 T12（构造性优先）
是架构自己的既有原则，此处未被应用。修复=把既有原则用到关系/成员界面。

**修法形状与相容性**。成员救援：当且仅当 (a) 关系类型 ∈ {CAUSE, SEQUENCE}
（CONTRAST 无 staged 见证，被拖是**正确**行为，域外），(b) own 为
staged_matched，(c) 该成员自己的 side 检查（rel2/rel3）= matches，
(d) 该成员裁决为平坦 U——则升为 S 并引用链句 sid。
这是标准 K2：域=平坦集；前提=(a)–(c) 皆为已完成的单跳检查，结论有引用；
失败回 U。单调性暴露面零新增：staged S 已经承诺了 matches 的
instance/subset 容忍（T7 前提一），救援只是让成员与关系的既有承诺一致，
不添加新推理。C 成员永不触碰（C 自信，不在域内；且 T6a 的否决权保留）。
**预登记验收**：r03（旁支触发）必须仍 U——其 side 是 mismatch，条件 (c)
不满足，救援按构造不触发；r08/r09 的 C 传播不变；relprobe 其余不变。

### 7.3 ④false C 收紧

**必要性（定义违反）**。定义 2 的 C 条款（R1）：仅当源**显式**陈述不相容。
实测 C 输出正确率 25–29%（random200 8 个 C 对 2 个；m08a"罚了子公司"被
读成与"罚母公司"排他）。错误模式是模态辖域混淆：把 D ⊭ φ（没证实）当成
D ⊨ ¬φ（证伪）——这恰是三值语义里 U 与 C 的分界线。C 输出在约四分之三
的情况下违反自己的定义条款，且 C 是严重度最高、对使用者后果最重的输出。

**修法形状与相容性**。对自信的 C 加一道**对立性过滤**：复用 T7 已证的
三分词表（matches/opposite/different），单跳问"被引句对 claim 是陈述了
**对立**（同一事物、同一方面、取值相反）还是**不同**（另一实体/方面/机制）"
——different ⟹ 降 C 为 U。这是纯 K1 算子，引理 K1 直接给出：
**S 集合不动（N1）、标记集不变（N3：C→U 后单位仍被标记，span 覆盖逐字
不变——成立条件：④运行于 embed 复判之后、不触发下游重写，管线顺序已如此
固定）**。换言之④在"新增放行"与"标记覆盖"两个维度上按构造零风险；
真 C 被降为 U 的严重度信息损失是它唯一的代价维度，被过滤器自身精度约束。
词表语义与 staged 完全同源，不引入新概念。
**预登记验收**：r08、r09、b05、m04b（全是同方面取值相反的真 C）必须
穿过过滤器仍为 C；m08a（异实体）应降为 U；RAGTruth 片段检出按证明不可能降，
复测仅为确认。

### 7.4 三者互不冲突（审查修订：按固定管线顺序逐步验证，而非域不交）

〔A7〕初版"初始域互斥 ⟹ 组合安全"不成立：K2 的输出（S）会进入 K1 的输入域
（S→U），顺序决定结果（先③后 gate 与先 gate 后③不同）——初版自己写的
"升 S 产物仍受 gate 节制"就承认了这种连接。正确的论证是对**固定的管线顺序**
（裁决+gate → 关系 staged → embed 复判 → ④过滤 → bridge → ③救援 → 合并 →
round4）逐步验证每个算子的前置条件不被前序破坏；本轮已真实踩过并修掉一个
该类 bug（embed 复判会复活被④降级的 C，靠把④排在其后解决）。
三个算子的触发特征：①域 = 自信 S 且带诊断部件（gate 内部）；
③域 = CAUSE/SEQUENCE 关系的平坦成员且 staged_matched；④域 = 自信 C。
逐步核查（二轮审查修订，B04）：④的 C→U 产物不带 low_confidence 旗标
（不入③/bridge 域）✓；①只改 gate 的开火谓词，不产生新裁决值 ✓；
但**③/bridge 升出的 S 目前不再经过 gate**——初版"仍受 gate 节制"经源码
核查为假（apply_grounding_gate 仅在判定轮、embed 复判、round4 三处调用，
两个救援之后没有），带未接地诊断部件的平坦 U 被救成 S 后其出处义务从未
复核。这是确认的检查义务缺口，修法 = 救援后对带诊断部件的单位复跑 gate。三者都不触碰切分逻辑、聚合规则、
staged 组合、bridge 前提——即 T1–T12 的全部陈述在修复后逐字成立，
需要改动的只有 7.1–7.3 各自新增的算子条款。

### 7.4b 实施与验收（2026-10-21，按预登记标准）

实现：①=gate 内的逐字在场见证（归一化子串匹配，允许剥掉一个引导连接词，
失败关闭）；④=c1 对立性单跳问题 + K1 降级（嵌在裁判轮之后、embed 救援
之后，防止重判复活被降的 C）；③=成员救援（仅 CAUSE/SEQUENCE、仅
staged_matched、仅平坦成员，引链句为证）。

验收逐项：

- 单测 84/84（新增三算子各一条；③的测试还顺带证实了一个好性质：救援凑齐
  全 S 会自动触发 round-4 整句复查——K2 升级自带一道二次防线）；
- 探针：**一轮验收回路**——首轮 r08 的真 C 被④误降（"only builds the
  syntax tree" 的排他构式被判 different），按预登记回路改 opposite 选项
  措辞（明确"排他性限制也算 ruling out"）复测：r08/r09/b05/m04b/m02 全部
  保 C，m08a 保持降级 U。最终 mathprobe **17/17**（m08a 修复达成）、

  复跑回 S，记入切点抖动台账）；
- RAGTruth 900（OP11）：片段检出 94.9%→**95.3%**（验收要求不降 ✓），
  strict 27.1%→**27.8%**，C 总量 284→**117**（④降级 170 处）；

诚实记录：①③在 900 条上的触发面很小（见证 1 次、救援 1 次）——这两类
错误在文案回正后的数据上本就稀有，收益主要是关死危险向通道而非拉分；

### 7.5 全局必要性（为什么是这三个、为什么不能靠调参）

三者合计 ≈ 6–7 个点的**已定位、违反自家公理**的错误质量（random200:
3+4+6=13/35）。〔审查修订，A10〕关于调参的对比，正确说法是：无差别放宽
阈值同时扩大接纳集合，新增接纳是否含错取决于边际分数段的错误率——这是
**风险**不是定理（存在只放进正确 S 的反例）；而见证驱动算子只在持有可检验
前提处行动，不做无差别移动。预登记改善实验纪律，不自动消除开发集过拟合，
泛化仍由冻结的正式评测集把关。
这也是对"过拟合"担忧的结构性回答：三个算子的机制里不含任何案例知识，
预登记的验收全部是已存在的探针和不变量。

## 8. 第二轮自我反例搜索（2026-10-21 深夜，攻击修订后仍成立的证明）

（第二批反例集）再实跑；其中一项不花钱、纯代码判定。
结果：**两个危险向失败实锤（n02、n05）、一个代码级 bug 确定性证实（n04 离线

### 8.1 P-assert 前提缺失：staged 路径的断言性洞（n02 实锤，最重）

T5/T7/成员救援全部默认一个没写出来的前提：**源链句自身被源断言**。
rel1 的问题明文接受"任何陈述了此类链的句子"——条件句内、转述内、否定内的
链都合格。audit09 修掉的是**答案侧**辖域；**源侧**完全对称的洞没有任何守卫。

n02 实测（源："If the beta flag is enabled, requests are compressed, so
bandwidth usage drops."；claim 无条件断言该链）：**全链假 S**——两个成员
判 S（0.83/0.98，判官把条件内内容当已断言内容），staged matched 给 S，
round 4 复查跑了且整句也判 S，**四道概率防线同时失守**。

这给 7.0 框架补上一刀（措辞按二轮审查 B08 收窄）：n02 的四防线共同失效
是**一次观察**，提示共享判官的防线存在相关误读；它不能证明相关的程度，
也不能证明叠层对同源偏差一概无收益（正相关守卫仍可降低联合逃逸率，只有
完全重合时增益为零）。正确的框架条款是：**没有独立性证据时，不得把各层
错误率相乘当安全界**；相关程度要靠评测测，不靠单例推。

n01（转述链）形式上同洞，这次**靠撤刀守卫的巧合**躲过（because 切被接受后
右片段恰好 2 词被并回→整句→判 U）——不是设计内防线，片段长 3 词就会漏。
n03（链级否定）这次被 V 层接住，但组合规则确实没有链极性阶段（rel1 任意
极性 + side 只看内容），形式风险在账上。

修法方向（待拍板）：rel1 问题文本加断言性约束（"the sentence itself
ASSERTS the link — not inside a conditional, reported speech, or negation"）
或增设 rel5 单跳"链句是否无条件断言该链"；成员救援继承同一前提；
裁决问题 V 对"内容仅在条件/转述内出现"的措辞同步收紧（n02 里 V 是第一道
失守的防线）。

### 8.2 词表有界性（n05 实锤）

条件辖域守卫——以及整个切点体系——的触发面等于连接词词表。
"**Should** the watchdog fire, the service restarts because memory is
exhausted." 无 if/unless/when 标记 → 无候选 → 守卫不触发 → because 切被
接受，"memory is exhausted" 再次被抬成独立 S 断言（0.93）——audit09 的
辖域提升在词表外形态上原样回归。

定理措辞必须降级："条件句不切"→"**词表内**条件标记且分类正确时不切"。
词表外清单（探针素材）：倒装条件（Should/Had/Were…）、祈使条件
（Do X and Y happens）、介词条件（In case of X）。

### 8.3 见证幻影匹配（确定性证实，代码级）

7.1 的前提"在场是可判定的字符串性质"在**归一化不保句界**处被打穿：
verbatim_in_source 在整个 passage 的归一化串上找子串，句号被抹掉，
"…the server restarts. Daily backups…" 拼出 "the server restarts daily"——
对源中从未作为一个断言存在的跨句内容返回 True（纯代码判定，无需 API；
对照组真在场 True、真不在场 False 均正确）。修法唯一：按句归一化匹配。
live 触发需要 V=S ∧ g 探针低 ∧ 跨句幻影三者同时（n04 实跑中 V 直接给了 U，
未行使），面窄但确定存在。

### 8.4 对立性过滤与引用质量的耦合（结构性）

c1 只看 evidence_sentence_ids：真 C 配上错引用会被
过滤器降级；两句联合才构成的矛盾也被"at least one cited sentence"措辞错杀
（T6d 在证据层的重演）。记为已知耦合，待引用质量战役一并处理。

n06 对照全 S（攻击无过度收紧误伤）；n03 被 V 层接住。本轮净结论：

## 9. 元话语门与平坦升级的可组合性（2026-10-22，"是否互斥"的形式回答）

设回答 A 的句子集 Sent(A)。两个算子：

- **M（资格门）**：E ⊆ Sent(A) 为被排除句（meta_discourse p≥0.80），单元只从
  Sent(A)∖E 生成——M 作用于**句子层**，发生在一切判定之前；
- **R（平坦升级）**：dom(R) = { u ∈ FactUnits : V(u)=U ∧ flat(u) }，把带证书的
  平坦 U 升为 S——R 作用于**已存在单元的判定层**，发生在一切廉价救援之后。

**定理 9.1（域不交与良定义，按修订版 7.4 的逐对核查而非泛化域不交论证）**
被 M 排除的句子不生成任何单元，故 dom(R) ⊆ Judgments(Units(Sent(A)∖E))，
与 M 的作用对象（E 中句子）交集为空——不是"碰巧不交"，是**下游域由上游
余象构造**。两算子无共享可变对象；固定顺序 M→判定→廉价救援→R→gate→round4
下逐项核查前置条件：M 不改其余句子的单元、证据或语境（排除只影响单元生成，
describe_unit 只携带单元自己的句子）；R 的输出重新过 gate（B04 纪律，已实现）
并可触发 round4——两者皆为向 U 的 K1 方向，只能把 R 的结果往保守侧拉。
∴ 复合 R∘M 良定义且无前提互毁，**互斥不成立**。∎

**定理 9.2（条件化逐点不退化，OST §4 的实例化）**
前提 P_M：被排除句均为金标 NONCLAIM（排除正确）；前提 P_R：证书健全
（Check 接受 ⇒ 金标 S）。则对每个单位分三类：被排除者由 P_M 从"错误输出
claim"变为"正确 SKIP"（损失不增）；被升级者由 P_R 从错 U 变对 S（损失减）；
其余不动。故逐点损失 L(R∘M(x)) ≤ L(x)，对任意输入分布取期望同向。
**前提是概率性的，且实测给出了两个方向的裁决**：OP17 测得 P_M（宽措辞版）
与 P_R 双双违反（11 + 6 个金标 span 被吃）；OP18 测得收窄版 P_M 在抽样上
成立（排除 4/4 正当）而 P_R 仍无证书级检查。于是 M 上线、R 挂起——
**这是前提的经验状态不同，不是两算子互斥。**∎

**定理 9.3（错误归因可分离性）**
Err_M（排除错误）发生在不存在单元的句子上，Err_R（升级错误）发生在存在且
被升级的单元上：Err_M ∩ Err_R = ∅ **由构造成立**（被排除的单元不存在，
无从被升级）。推论：四臂消融的归因是良定义的——OP17 的 17 个新漏恰好分解为
11（M）+ 6（R）、无重叠，实测与定理一致。∎

**推论（耦合均良性）** (a) M 使 dom(R) 单调收缩：健全性逐元素定义，在子域上
保持；(b) R 的升级可凑齐全 S 触发 round4——round4 属 K1 方向（父覆盖只降不升），
N1/N2 不受损。终局形态 = 两算子叠加运行；当前 (M 开, R 关) 纯因 P_R 未达标，
R 补齐证书级 Check 并重过预登记验收后即可与 M 共存，无需任何互斥让位。
